# 🛒 Simple Shopping Cart App

A simple Flutter application built to practice state management using the **Provider** package.

## ✨ Features

- **Home Screen:** View a list of products and add them to the cart.
- **Cart Badge:** Live item count in the app bar.
- **CheckOut Screen:** View selected items, remove products, and see the live total price.
- **Empty State:** Shows a clean message when the cart has no items.

## 🚀 Getting Started

1. Clone the repository and navigate to the project folder.
2. Run the following command to get dependencies:
   ```bash
   flutter pub get
   ```
